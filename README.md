# CSE421 Ka Chow Net

A **CSE421 Computer Networks** project developed using Cisco Packet Tracer.

## Project Overview

This repository contains the Cisco Packet Tracer project file for **Ka Chow Net**. The network demonstrates the configuration and implementation of networking concepts covered in CSE421.

## Contents

* `CSE421-Ka-Chow-Net.pkt` — Cisco Packet Tracer project file
* `README.md` — Project documentation

## Tools Used

* Cisco Packet Tracer
* Computer Networking concepts from CSE421

## How to Open

1. Download the `.pkt` file from this repository.
2. Open it using **Cisco Packet Tracer**.
3. Explore the network topology and device configurations.
4. Use **Simulation Mode** to observe packet flow and network communication.

## Project Features

* Network topology design
* Device configuration
* IP addressing
* Routing and switching concepts
* End-to-end connectivity testing
* Packet flow analysis using Cisco Packet Tracer
